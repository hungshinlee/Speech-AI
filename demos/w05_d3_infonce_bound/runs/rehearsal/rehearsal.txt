1  真值與天花板：I 有閉式解，ln N 是 InfoNCE 估計值的上限
────────────────────────────────────────────────────────────────────────
資料：d = 8 維高斯對，每一維 y = ρx + √(1−ρ²)·ε，ρ = 0.7
真值：I(x; y) = −(d/2)·ln(1 − ρ²) = −4·ln(0.51) = 2.6934 nat
天花板過真值的條件：ln N > I  ⇔  N > e^I = 14.8，也就是至少 15 個樣本（14 個負樣本）

b  純雙線性 critic（a ≡ 0）：少了 ‖y‖² 那一項，最佳 critic 不在模型族裡
────────────────────────────────────────────────────────────────────────
高斯對的 log 密度比 ln p(y|x)/p(y) 是 x、y 的二次式：xᵀ(·)y 之外還有 ‖y‖² 一項（與 x 無關的 ‖x‖² 項在列內 softmax 裡消掉，‖y‖² 消不掉）。
最佳 critic 的那一項：a* = −ρ²/(2(1−ρ²)) = -0.480（鍵 2 學到的 a 在最後一欄，拿來對）
     N     ln N      雙線性     多一項 a       差   (a 的學到值)
     8    2.079    1.294     1.543   0.249   (a = -0.529)
   128    4.852    1.869     2.482   0.613   (a = -0.490)
  1024    6.931    1.944     2.652   0.707   (a = -0.479)

兩個都是合法的下界（p11 第五行對任何 critic 成立），差的是**鬆緊**：critic 族裡沒有最佳 critic，下界就緊不起來。
